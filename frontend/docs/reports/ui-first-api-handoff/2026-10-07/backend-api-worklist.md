## 8. Thứ tự triển khai và điều kiện bàn giao

1. **Nền tảng:** khóa các quyết định mục 2 và 6; làm tài khoản/quyền/ownership cùng các catalog cần cho form.
2. **Luồng chính:** DNA → tạo bản nháp → đọc Planner → chat/chỉnh ràng buộc/thứ tự → xác nhận → chuyến của tôi/publication/cộng đồng.
3. **Phần còn lại:** nội dung dùng chung, phản hồi và quản trị, trace/metrics, thực thể/import, Golden Dataset. Gói/hóa đơn chỉ trong scope đọc.
4. **Có điều kiện:** chỉ mở việc cho 5 API ở mục 5 khi chủ sản phẩm và hai đội chốt luồng.

Một mục chỉ được đóng khi Backend công bố mapping endpoint chính thức, đối chiếu đủ dữ liệu theo link FE, nêu các khác biệt đã được hai đội chấp thuận và cung cấp bằng chứng hoạt động/quyền/lưu dữ liệu tương ứng. Việc frontend đã có service hoặc backend có route **không chứng minh đã tích hợp UI**.

**Giới hạn review:** tài liệu này là backlog từ hai tài liệu được cung cấp; không xác nhận API production, không chạy tích hợp, không thay đổi hai tài liệu gốc hoặc FE/BE code.
