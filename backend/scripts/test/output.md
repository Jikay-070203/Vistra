The admin place-import API stores the place metadata in PostgreSQL. It does not create an embedding or upsert a vector into Qdrant. Qdrant is only checked for readiness/collections here; a real vector must be generated by the embedding/indexing pipeline before a point is inserted.

## AI provider API response

### `PUT /api/v1/admin/ai/provider`

Response thực tế khi cập nhật Gemini:

```json
{
  "data": {
    "provider": "gemini",
    "model": "gemini-3.5-flash-lite",
    "hasKey": true,
    "updatedAt": "2026-10-09T07:19:11.706796+00:00",
    "message": "AI provider updated",
    "recommendedModels": {
      "gemini": ["gemini-3.5-flash-lite"],
      "openai": ["gpt-4o-mini"]
    }
  }
}
```

`hasKey: true` chỉ xác nhận key đã được lưu mã hóa; API không trả API key thật.
Các lần chạy test sau sẽ tự cập nhật phần này bằng response mới của:

```text
GET /api/v1/admin/ai/provider
PUT /api/v1/admin/ai/provider
```
