# VISTRA Backend API — Báo cáo cập nhật 08/10/2026

## Quy ước

- Production: `https://vistra-backend-production.up.railway.app`
- Local: `http://localhost:8000`
- Auth dùng cookie HttpOnly: `vistra_session` (30 phút), `vistra_refresh` (1 ngày).
- Ảnh được frontend upload lên Cloudinary; backend chỉ nhận và kiểm tra URL.

## 1. Phân tích ảnh Travel DNA

### `POST /api/v1/dna/analyze`

Giới hạn: tối đa 3 ảnh/request; mỗi ảnh tối đa 5 MB (`5242880` bytes); định dạng JPEG, PNG hoặc WebP; URL phải thuộc Cloudinary; analysis hết hạn sau 24 giờ.

Request:

```json
{
  "image_urls": [
    "https://res.cloudinary.com/demo/image/upload/w_2000,q_auto,f_auto/travel-1.jpg",
    "https://res.cloudinary.com/demo/image/upload/w_2000,q_auto,f_auto/travel-2.webp"
  ],
  "description": "Thích thiên nhiên và lịch trình vừa phải"
}
```

Response `201 Created`:

```json
{
  "analysis_id": "analysis-uuid",
  "status": "completed",
  "derived_dna": {
    "metrics": [],
    "pace": null,
    "scenery_focus": null,
    "cuisine_priority": null,
    "suggested_interests": []
  },
  "suggested_trip_dna": { "metrics": [] },
  "confidence": null,
  "expires_at": "2026-10-09T08:00:00+00:00",
  "sources": [
    {
      "id": "source-uuid",
      "url": "https://res.cloudinary.com/demo/image/upload/travel-1.jpg",
      "filename": "travel-1.jpg",
      "status": "processed"
    }
  ],
  "notice": "Images validated; no vision model is configured yet."
}
```

Lỗi chuẩn `422`:

```json
{ "detail": { "code": "IMAGE_COUNT_INVALID", "message": "Attach between 1 and 3 images" } }
```

```json
{
  "detail": {
    "code": "IMAGE_TOO_LARGE",
    "message": "Each image must be <= 5 MB and JPEG, PNG, or WebP",
    "sources": [{ "status": "rejected", "error": "IMAGE_TOO_LARGE" }]
  }
}
```

Các lỗi khác:

```json
{ "detail": { "code": "IMAGE_URL_INVALID", "message": "image_urls must contain HTTP(S) URLs" } }
{ "detail": { "code": "IMAGE_HOST_INVALID", "message": "Images must be hosted on Cloudinary" } }
{ "detail": { "code": "IMAGE_UNAVAILABLE", "message": "The image could not be downloaded from Cloudinary" } }
```

Chưa đăng nhập trả `401`:

```json
{ "detail": { "code": "UNAUTHENTICATED", "message": "Sign in required" } }
```

## 2. Tạo trip với DNA riêng

### `POST /api/v1/trips`

Request bổ sung:

```json
{
  "destination": "ninh-binh",
  "start_date": "2026-11-10",
  "days": 3,
  "people": 2,
  "budget_vnd": 5000000,
  "budget_scope": "total",
  "transport": "car",
  "pace": "normal",
  "notes": "Ưu tiên cảnh quan",
  "dna_analysis_id": "analysis-uuid",
  "travel_dna_override": {
    "metrics": [{ "key": "nature_vs_city", "score": 80 }],
    "pace": "relaxed",
    "scenery_focus": "nature",
    "cuisine_priority": "local"
  }
}
```

Response `201 Created` gồm `id`, `owner_user_id`, `status`, `request`, `travel_dna`, `itinerary` và `generation_error`:

```json
{
  "id": "trip-uuid",
  "owner_user_id": "user-uuid",
  "current_version": 0,
  "status": "draft",
  "request": { "destination": "ninh-binh", "days": 3, "notes": "Ưu tiên cảnh quan" },
  "travel_dna": { "metrics": [{ "key": "nature_vs_city", "score": 80 }] },
  "itinerary": null,
  "generation_error": null
}
```

Analysis thiếu, hết hạn hoặc không thuộc user trả `422`:

```json
{ "detail": "DNA analysis is missing, expired, or belongs to another user" }
```

## 3. Đọc trip detail an toàn

### `GET /api/v1/trips/{trip_id}`

Chỉ owner được đọc trip private. Thành công `200` trả detail gồm `request`, `travel_dna`, `itinerary`, `recommendations`.

```json
{
  "id": "trip-uuid",
  "owner_user_id": "user-uuid",
  "current_version": 1,
  "status": "draft",
  "request": {},
  "travel_dna": {},
  "itinerary": { "days": [] },
  "recommendations": []
}
```

Thiếu session trả `401`; trip không tồn tại hoặc không thuộc user trả `404`:

```json
{ "detail": "Trip not found" }
```

### `GET /api/v1/community/trips`

Query hỗ trợ: `page`, `page_size`, `q`, `province`, `duration`, `tag`, `budget_min_vnd`, `budget_max_vnd`, `liked_by_me`.

Ví dụ: `/api/v1/community/trips?province=ninh-binh&duration=3&tag=food`.

## 5. Frontend validation khuyến nghị

```ts
const MAX_IMAGE_BYTES = 5 * 1024 * 1024;
const MAX_IMAGES = 3;

if (files.length > MAX_IMAGES) throw new Error("Chỉ được chọn tối đa 3 ảnh");
if (files.some((file) => file.size > MAX_IMAGE_BYTES)) {
  throw new Error("Mỗi ảnh không được vượt quá 5 MB");
}
```

Frontend nên upload Cloudinary với `w_2000,q_auto,f_auto`. Backend vẫn kiểm tra lại để bảo mật.

## 7. Các cập nhật bổ sung từ backend blocker review

### Quyền owner khi tạo trip

`POST /api/v1/trips` bắt buộc có `vistra_session`. Backend tạo trip với `owner_user_id` của user hiện tại.

Không có session:

```http
401 Unauthorized
```

```json
{
  "detail": {
    "code": "UNAUTHENTICATED",
    "message": "Sign in required"
  }
}
```

### Chat riêng của trip

`POST /api/v1/trips/{trip_id}/chat` yêu cầu user đăng nhập và phải là owner của trip.

User khác hoặc trip không tồn tại:

```http
404 Not Found
```

```json
{ "detail": "Trip not found" }
```

### Atomic version control

Các API confirm, publish và update trip đều kiểm tra `base_version` trong cùng thao tác cập nhật database.

Nếu có request khác cập nhật trước:

```http
409 Conflict
```

```json
{ "detail": "Trip changed. Reload before updating" }
```

Confirm dùng message:

```json
{ "detail": "Trip changed. Reload before confirming the plan" }
```

Frontend cần reload trip detail trước khi thử mutation lại.

### Reject field không hỗ trợ

`PATCH /api/v1/trips/{trip_id}` hiện chỉ nhận:

- `base_version`
- `status`
- `is_published`

Nếu gửi field khác, backend trả:

```http
422 Unprocessable Entity
```

```json
{
  "detail": {
    "code": "UNSUPPORTED_TRIP_FIELDS",
    "fields": ["unknown_field"]
  }
}
```

### Public CMS content

### `GET /public/content`

Public landing đọc các bản ghi active từ `content_items`, sắp xếp theo `sort_order` rồi `id`.

Response:

```json
{
  "heroPlans": [],
  "introDestinations": [
    {
      "id": "intro-uuid",
      "label": "Ninh Bình",
      "provinceCode": "ninh-binh",
      "imageUrl": "/media/ninh-binh.jpg",
      "tagline": "Thiên nhiên và di sản",
      "active": true,
      "order": 0
    }
  ],
  "allergyOptions": [
    {
      "id": "seafood",
      "label": "Hải sản",
      "active": true,
      "order": 0
    }
  ]
}
```

Các item có `active=false` không xuất hiện trong public response. Nếu CMS chưa có intro hoặc allergy data, backend dùng catalog destination/allergy mặc định làm fallback.

### Quy tắc triển khai frontend

Frontend không nên coi status `200` là mutation thành công tuyệt đối. Với trip mutation cần xử lý:

- `401`: yêu cầu đăng nhập lại.
- `403`: không đủ quyền.
- `404`: trip không tồn tại hoặc không thuộc user.
- `409`: reload dữ liệu vì `base_version` đã cũ.
- `422`: payload có field hoặc giá trị không hợp lệ.
